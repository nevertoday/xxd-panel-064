# 🦁 XXD Panel 064

### 写真を、静かで不完全な、時間に満ちた古い紙のコラージュ ファイルに変換します。

<a href="README.md">简体中文</a> · <a href="README.en.md">English</a> · <a href="README.ja.md">日本語</a> · <a href="README.ko.md">한국어</a> · <a href="README.ar.md">العربية</a>

Panel 064 は、手で引き裂いた紙の端、古い紙のテクスチャ、鉛筆やインクの線、薄めたテキストの断片、およびごく少量のソース画像のアクセントカラーを使用して、白い空間に空気、時間、静寂、記憶を表現します。

**キーワード:** 古い紙のコラージュ · 手で引き裂かれたエッジ · アーカイブの雰囲気 · タイプライターの小さな活字 · 詩的な空白

## 使用する

```text
/xxd-panel-064 photo.jpg --mode design-only --size 3:4 --text prompt --locale ja-JP
```

単一画像、ディレクトリ バッチ、4 つの出力モード、複数のサイズ、および 3 つのテキスト モードをサポートします。完全な動作については、[SKILL.md](SKILL.md) を参照してください。
